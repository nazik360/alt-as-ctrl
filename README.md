# Alt as Ctrl (Fabric, Minecraft 1.19.2)

Клиентский мод: действия с Ctrl (Ctrl+Q выбросить стак, Ctrl+клик, Ctrl+A/C/V) работают с Alt.
Только клиент: друзья заходят к тебе без мода, на чужие сервера тоже можно.

Настройка: config/alt-as-ctrl.properties, altOnly=true -> настоящий Ctrl в GUI перестаёт работать как Ctrl.

Сборка (JDK 17+):  gradlew build   ->  build/libs/alt-as-ctrl-1.0.0.jar в папку mods (+ Fabric API).
